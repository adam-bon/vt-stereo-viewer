Through the red lens only: the cyan ring should be solid black and the red ring should vanish. Red ring shows dark → lower the background's red. Shows light → raise it.

Through the green lens only: the red ring should be solid black and the cyan ring should vanish. Cyan ring shows dark → lower the background's green. Shows light → raise it.

Only an outline left? Softness 0 gives hard pixel edges with no in-between colours. Softness above 0 blends the edge in linear light using the gamma value, so an edge that stays balanced at 2.2 but not at 1.0 confirms it was the blending. Subpixel shift slides the red channel sideways by tenths of a pixel to counter the LCD's red/green subpixel offset.

Arrow keys move base in / out (Shift for bigger steps). Where the rings cross, each channel multiplies, which is what both eyes seeing dark looks like.
