Setup: Beast in 3D mode at 1200p, so the computer sees a 3840×1200 display. Open this page on it and press F; each eye then gets a full 1920×1200 picture. H hides this panel (it only shows in one eye); the slider along the bottom is in both halves so it fuses. Screen size and distance are set on the Beast, so separations here are shown in pixels.

Tuning: through the red lens only, the cyan ring should be solid black and the red ring should vanish — red ring shows dark → lower the background's red; shows light → raise it. Through the green lens only, the red ring should be black and the cyan ring vanish — cyan shows dark → lower the background's green. Softness 0 gives hard edges; above 0 the edge blends in linear light with the gamma value. Subpixel shift slides the red channel sideways to counter the LCD's red/green subpixel offset.

Gallery: the Image list holds the flat ring plus whatever is in images/, found automatically on GitHub Pages or a local server (images/manifest.js is the fallback for hosts that can't be asked); [ and ] cycle. A pair named name_left / name_right becomes one entry, a single file is used for both eyes. The file picker adds more for this session only. Images are scaled so their width matches the ring size. Anaglyph needs the page served over http to read image pixels; side by side works either way.

Blur: softens one eye's whole picture, in tenths of a pixel up to 20 px — the on-screen version of a blur foil over one lens. Blurring the dominant eye lowers its pull so the other eye's input counts for more; blurring both removes fine detail so fusion has to run on coarse shapes. Side by side only.

Prism: each slider shifts one eye's whole picture, like prism in that lens — positive is right / down. The ↻ sliders rotate one eye's whole picture about its centre, in tenths of a degree, for torsion. Set them once where a fused target looks single and level, then leave them; ↑ ↓ nudge the right eye's vertical (Shift for bigger steps). About 22 px per Δ on the Beast. Base in / out stays the exercise control on top of this.

Contour background: faint, irregular contour lines across the card, identical in both eyes, so the card itself is a textured surface at zero disparity. That gives the eyes something to fuse everywhere and makes it easier to judge how far a quoit has left the card. Irregular on purpose: a regular grid can be fused at the wrong repeat.

Centre dot: a solid dot at the centre of each quoit, identical in both eyes, so it stays on the card plane whatever the quoit does. When the quoit floats or sinks the dot stays put; if you fixate the dot instead of the ring the ring doubles, and vice versa.

Several quoits: up to three, stacked top to bottom, each with its own base in / out. Pick which one the slider and arrow keys move with 1 2 3 (a marker at the left edge shows it); the others stay where you left them, so you can hold one on the card and float or sink another, or jump fixation between planes.

Keys: ← → base in / out (Shift for bigger steps), 0 to align, 1 2 3 pick the quoit, [ ] gallery, D centre dot, C contours, M switch mode, X swap eyes, H panel, F fullscreen.
